# Israa Shawqi — Portfolio

موقع بورتفوليو لإسراء شوقي، مديرة متاجر Shopify في دبي.
مبني بـ [Astro](https://astro.build) + [GSAP](https://gsap.com)، وبيطلع صفحات HTML جاهزة وسريعة.

- إنجليزي (الأساسي) على `/`، وعربي على `/ar/`
- الوضع الفاتح هو الأساسي، ومعاه زرار للوضع الداكن
- الصفحات: الرئيسية · Work · About

## فكرة التصميم

نفس هوية الموقع القديم: الأخضر `#2d6a4f` والمنت `#d8f3dc` والكريمي `#faf7f2`، وخط Playfair Display للعناوين وDM Sans للنص
(وبالعربي Amiri وIBM Plex Sans Arabic). الفكرة إن الموقع شبه **لوحة تحكم متجر**:

1. **الواجهة** — البانل الأخضر بالسهم زي الأصل، وجنبه "لوحة متجر" حية: طلبات بتوصل وبتتنفذ، وعدّاد، ورسم بياني، وإشعارات.
2. **الأرقام والأدوات** — الإحصائيات بتعد لوحدها، وشريط الأدوات بيتحرك.
3. **الخدمات** — نفس الكروت، والأخضر بيملا الكارت من مكان الماوس.
4. **المتاجر** — كل متجر جوه شباك متصفح باسم الدومين، وبيميل مع الماوس.
5. **طريقة شغلي** — 4 خطوات، والخط بينهم بيترسم مع السكرول.
6. **تواصل** — نسخ الإيميل والرقم بضغطة، و"ليه تشتغل معايا"، وفورم صغير بيفتح واتساب برسالة جاهزة.

## التشغيل محلياً

```bash
npm install
npm run dev      # http://localhost:4321/
npm run build    # يطلع الموقع الجاهز في dist/
```

## النشر على Hostinger

Hostinger بينسخ المستودع زي ما هو في `public_html` ومش بيعمل build، عشان كده:

- الموقع الجاهز موجود في فولدر `dist/` ومرفوع على المستودع.
- ملف `.htaccess` اللي في الروت بيوجّه كل الطلبات لـ `dist/`.
- أي تعديل في `src/` أو `public/` بيتعمله build تلقائي من GitHub Actions، و`dist/` الجديد بيترفع لوحده.

لما يبقى فيه دومين: حطه في `SITE_URL` في `astro.config.mjs`، وده بيشغّل الـ canonical والـ sitemap.
